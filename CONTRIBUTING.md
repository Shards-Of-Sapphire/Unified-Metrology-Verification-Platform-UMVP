# Contributing to UMVP

## Contribution Guidelines
We welcome contributions from:
- State Legal Metrology Departments
- Government Approved Test Centres (GATCs)
- Authorized developers & vendors
- Academic institutions under MoU with DoCA

## Process
1. **Fork** the repository
2. Create a feature branch (`git checkout -b feature/state-name`)
3. Commit changes with descriptive messages
4. Submit a Pull Request with:
   - Problem statement
   - Proposed solution
   - Testing evidence
   - State/LMO reference (if applicable)

## Code Standards
- Follow TypeScript/ESLint configuration
- Include unit tests for new features
- Update documentation for API changes
- Maintain backward compatibility for existing integrations

## Security
- Report security vulnerabilities to: security.umvp@gov.in
- Do NOT include sensitive data in issues or PRs
- Follow GoI security guidelines for government systems
